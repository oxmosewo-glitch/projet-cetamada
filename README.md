# Écorché de baleine à bosse

Écorché anatomique interactif d'une baleine à bosse en radiographie, qui suit sa migration de l'océan Austral jusqu'aux eaux tropicales où elle se reproduit.

OXMOSE, Gatien Leclère.

- `index.html` : l'écorché (fichier autonome, three.js chargé depuis jsDelivr)
- `parcours/` : le parcours de fabrication
